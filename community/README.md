# Participate

Start with a small, reproducible task. Reports in English or Chinese are welcome.

| Your goal | Entry point |
|---|---|
| Try TOMC and report a successful or blocked first run | [Shared first-run thread](https://github.com/ZipengWu365/TOMC/issues/11) |
| Report a distinct TOMC bug | [Issue templates](https://github.com/ZipengWu365/TOMC/issues/new/choose); include version, environment and a synthetic reproduction |
| Contribute code or a documentation correction to TOMC | [Contribution requirements](https://github.com/ZipengWu365/TOMC/blob/main/CONTRIBUTING.md) |
| Read or discuss the reasoning behind an evaluation | [Research notes](../notes/README.md); use a focused issue in this profile repository for a correction to a note |
| Work on time-series software | [EchoTime](https://github.com/ZipengWu365/EchoTime) and [TSDecompose-Benchmark](https://github.com/ZipengWu365/TSDecompose-Benchmark); follow each project's contribution instructions |

## Follow the person or a particular project

Use **Follow** on [ZipengWu365's profile](https://github.com/ZipengWu365) for work across projects. Use a repository's **Star** to bookmark it and **Watch** settings for the notifications you want. No follow, star or public endorsement is required to receive help or contribute.

## Discussions status

As checked on 27 October 2026, TOMC Discussions was not enabled. The existing issue thread above is the live first-run reporting entry point. [Prepared discussion categories and opening posts](discussions-launch.md) are a setup pack, not a claim that a forum is already running.

## Reporting boundaries

Share minimal synthetic examples, relevant software versions and redacted logs. Do not upload API keys, private conversations, notebook databases, health records or unpublished research material. Distinguish a proposed integration from a tested one, and a single working example from broad benchmark evidence. Keep comparisons attached to their configurations and retain negative results.
