I build research software around time series, forecasting, benchmarking, and agent-readable scientific workflows.

Currently my public work is centered on turning time-series data into reproducible reports, benchmark artifacts, shareable packages, and machine-readable handoffs.

## Featured projects

| Project | What it demonstrates | Stack |
|---|---|---|
| [AgentForecast](https://github.com/ZipengWu365/AgentForecast) | Multi-backend, agent-friendly forecasting that exports publishable charts, cards, Markdown, and JSON. | Python, forecasting, agents |
| [TSDataForge](https://github.com/ZipengWu365/TSDataForge) | A time-series profiling and handoff layer that turns raw data into reports, dataset cards, decision records, and next-action plans. | Python, time-series profiling |
| [EchoWave](https://github.com/ZipengWu365/EchoWave) | Explainable structural similarity for time series and datasets, with plain-English summaries, HTML reports, and compact JSON. | Python, similarity, reports |
| [TimeSeriesCounterfactuals](https://github.com/ZipengWu365/TimeSeriesCounterfactuals) | Counterfactual workflow tooling for before/after time-series questions, including charts, reports, share packages, and agent-ready handoffs. | Python, causal impact, synthetic control |
| [SSE-Bench](https://github.com/ZipengWu365/SSE-Bench) | A benchmark for early warning of super-spreading social events from early event trajectories. | Python, benchmarking |
| [LetMeSeeYourGaitSignature](https://github.com/ZipengWu365/LetMeSeeYourGaitSignature) | Wearable accelerometer walking-state recognition comparing HMM, ESN, and Mamba-style temporal smoothing with CUDA paths. | Python, wearables, sequence models |

## Research and engineering focus

- Time-series forecasting and decomposition
- Counterfactual analysis and causal-impact style workflows
- Dataset profiling, benchmark design, and reproducible evaluation artifacts
- Agent-readable scientific outputs: JSON schemas, reports, summaries, and handoff bundles
- Wearable, biomedical, traffic, energy, and social-event time-series data
